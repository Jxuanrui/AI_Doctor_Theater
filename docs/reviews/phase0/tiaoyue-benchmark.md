> 来源（v3.1 修正）：**官方产品使用手册 PDF（79 页，用户提供，2026-10-10）**，存档 data/research/tiaoyue_manual.{pdf,txt}（不入 git）。官网 https://tiaoyueai.com/。用户最初给的 tiaoyue.com 现为待售页（candidate_research：暂无存档证据）。产品名以手册为准统一为**"跳跃视界"**（用户口误"眺悦"，仓库文档统一改称跳跃视界）。此前 v2 基于新闻稿的推断**全部以本手册为准重写**。

## 二、成片效果的四大工程杀器（差距根因，替换 v2 推断）

1. **全局资产 + @引用**：所有分镜提示词自动引用同一套角色/场景资产图作参考 → 跨镜头一致（我们的"官定底图单一首帧"是它的极简子集）。
2. **首尾帧截取（手册"秘诀一"）**：上一镜尾帧截图作为下一镜**首帧**参考 → 转场自然+时序连续（**我们完全没用**——LMD/Seedance API 均支持 first/last frame 双图，i2v_template 未实现）。手册将"全能参考"与"首尾帧"列为**两种互斥模式**（:368-371），同镜混用属 candidate_research；链式会累积眼色漂移、重做第 k 镜连带作废后续镜——须配虹膜色相闸门。
3. **多景别首帧**：多角度工具（8 水平+4 俯仰+3 景别，手册未写背后模型，是否依赖 Seedream 属推断）+垫图 → 特写/中景/全景交替（**我们已识别的瓶颈**；CogView 无垫图，替代路线见 §四）。
5. **人声/解说剧形态（监工补充的最大可感知差距）**：对方主打解说剧（角色带音色资产、自动配音），我方为猫叫+全字幕（用户 2026-10-09 拍板）——如实披露，不作为本轮改造项。
4. **BGM 合成+自动渲染**：成片链尾自动混 BGM（我们 A1 级已规划，ffmpeg 实现）。

## 四、复刻方案 v3（替换 v2 的 A/B/C）

### 第一优先：两大未用 API 能力（¥4-8 试验，杠杆最大）

1. **首尾帧链（方向已按监工更正）**：镜 A 出 4s → 抽尾帧 → 作为镜 B 的**首帧**（first_frame）输入再出 4s。Seedance 火山协议支持（LMD videoClient:4322-4332 已实现）。**预期效果：转场丝滑**（手册称"秘诀一"而非唯一核心）。试验：2 镜头链（~¥8：2×4s+重试余量）。
2. **i2v 多参考**：官定图+场景图双参考（role: reference_image）→ 不同景别/场景中保持 Dr.咪一致。**这直接解多景别瓶颈**（不必依赖 Seedream 垫图）。试验：1 条（~¥4）。此前 M3 失败系缺 role 参数（mini_test_report.json:5 "role must be specified"）。

### 第二优先：A1 纯后期（¥0，沿用 v2 并细化）

3. BGM+猫叫 ducking 混音、花字字幕、xfade 叠化、片头尾模板、空镜 Ken Burns（滤镜 9/9 已验证）——合成器重写（首尾帧链+混音+多轨字幕一体设计，B5 素材回归三验收）。

### 第三优先：成本与档位（待拍板沿用 v2）

4. 镜头节奏/预算三选一（¥59-85 重算不变）；Seedance 正式档 1 镜对比；NoToken 聚合档询问（此前悬置项，0.2 点/秒若开通则成本降 80%）。

### 第四优先：一键流（等 1-3 有对比结果）

5. make_episode.py（补 5 零件：CogView 出图/分镜生成/混音器/P10 闸门/虹膜色相闸门）。
