## 一、对方产品拆解（据新闻稿，candidate_research）

八大功能：剧本创作 / 创意生成 / 短剧一键流（剧本→分镜→定妆→出图→视频→配音→字幕→合成全自动）/ 可视化无限画布 / 视频转绘 / 资产生态（角色库+参考图锁定）/ 项目存储 / 成片导出（宣称 1080p、自动转场、BGM 智能匹配、花字字幕）。模型聚合：Seedance 2.0（视频）+ DeepSeek（剧本）+ 通义系（图像）。

## 三、复刻方案 v2（分级修正版）

### A1 级：纯后期 ¥0（先行，B5 素材即可出对比，不动 i2v）

1. BGM+环境音混音（猫叫轨 ducking；BGM/环境音按 governance §5 标准建许可台账后方可入库——"OGA 同源可取"属 candidate_research）
2. 字幕花字样式+顶部标题条（注意与右上"AI生成"角标避让）+关键词高亮
3. xfade 叠化转场（0.2s/切点）——**合成器需重写**：叠化缩短每切点时长，字幕时轴与音轨对齐逻辑全部要改（现 compose_episode.py concat+循环首段猫叫的设计不够），重写后须先跑 B5 素材回归（音画同步/字幕≤14字/AI标识全程可见三项旧验收）
4. 片头片尾模板（Dr.咪定妆字卡）
5. 空镜+Ken Burns（CogView 出空镜图+zoompan）

### A2 级：花钱的 i2v 项（并入 S2 试点验证，不得跳过/合并）

6. 运镜提示词库+复杂动作（"低头喝咖啡"**禁用**：咖啡因对猫有毒【candidate_research】，科普号出现猫喝咖啡会被质疑——改为"闻一闻/推杯子/指杯子"，最终由用户以医学校对人身份定夺）

### B 级：小额试验

### C 级：工程（新路径须报监工）

## 四、成本重算（P0-5）

镜头数 × 计费时长 × 重试率：假设 11 镜（8 猫镜+3 空镜）×4s×1.5 ≈ ¥48 + 图文 ¥5 + 正式档 1 镜 ¥4-8 + 时长实测 ¥2 ≈ **¥59-73**——下限即触 80% 上报线（¥56），**超 ¥70 总额风险真实存在**。缓解三选一（待用户拍板）：a) 成片缩至 20-25s（7-8 镜）；b) 空镜/静态推拉占比提高；c) 预算上调至 ¥100。

## 五、ffmpeg 滤镜可用性（P0-6，2026-10-10 实测原始输出）

`ffmpeg -hide_banner -filters | grep -oE '\b(xfade|zoompan|sidechaincompress|unsharp|hqdn3d|atempo|amix|adelay|volume)\b'` →
