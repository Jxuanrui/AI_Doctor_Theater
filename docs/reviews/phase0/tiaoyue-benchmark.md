# 对标分析：跳跃视界（tiaoyueai.com）成片效果差距与复刻方案 v3（2026-10-10，基于官方手册）

> 来源（v3 升级）：**官方产品使用手册 PDF（79 页，用户提供，2026-10-10）**，存档 data/research/tiaoyue_manual.{pdf,txt}（不入 git）。官网 https://tiaoyueai.com/（用户最初给的 tiaoyue.com 为待售域名，与手册"跳跃视界"的对应关系由 support@tiaoyue.com 邮箱域名佐证）。此前 v2 基于新闻稿的推断**全部以本手册为准重写**。
> 用户判断复核："对方是 harness（模型都一样）"——**大部分成立**（视频侧同源：Seedance 2.0 系；文本侧同源：DeepSeek/GLM/豆包/Qwen），**一处不成立**：图片侧对方用 Seedream 5.0/4.x、Midjourney 系（悠船）、即梦系——**支持垫图/多参考融合/角色一致性**，我们的 CogView-4 无参考能力，这是模型能力差异而非纯工程差异。

## 一、对方产品架构（手册 §1-8）

| 模块 | 核心机制 | 对成片效果的贡献 |
|---|---|---|
| 影视 Agent | 剧本(≤20万字)→全局设定→**全局角色/场景/道具资产自动拆解**（含妆造多时态）→分镜（**@资产引用**进提示词）→批量出片→导出；**解说剧一键成片**（整集自动拆段全量出片） | 一致性+自动化 |
| 分镜编辑 | 增删镜、**首尾帧截取**（上一镜尾帧=下一镜首帧参考）、**垫图参考**（构图/光影/站位）、AI 改写提示词 | **转场丝滑**+构图可控 |
| 图像工具 | **多角度**（8 水平环绕+4 俯仰+3 景别）、打光（26 光位+智能模式）、超清 4K、扩图/抠图、九宫格分镜、角色三视图 | **多景别一致首帧** |
| 短视频 | 三模式（Agent/图/视频直达）、**视频参考三模式（全能参考/首尾帧/智能多帧，图≤9 视频≤3）**、预计积分实时显示、**BGM 合成+最终渲染**自动 | 单条快出+成本透明 |
| 剧本中心 | 原创/爆款改编/IP 改编+拉片+协同编辑 | 内容侧 |
| 资产库 | 官方六大类目+项目/团队资产+**报白审核/合规拦截**（肖像白名单/版权 IP/内容红线） | 合规工程化 |
| 模型池 | 文本 8 家（GLLM/CLLM/豆包/DeepSeek/Qwen）、图片 7 家（**Seedream 5.0/4.x、即梦、Midjourney、Qwen-Image**）、视频 5 家（**Seedance 2.5/2.0/Fast/Mini**、Wan、海螺、可灵、Vidu） | 多档位多风格切换 |
| 商业 | 积分制（失败 2h 返还、额度管理） | — |

## 二、成片效果的四大工程杀器（差距根因，替换 v2 推断）

1. **全局资产 + @引用**：所有分镜提示词自动引用同一套角色/场景资产图作参考 → 跨镜头一致（我们的"官定底图单一首帧"是它的极简子集）。
2. **首尾帧转场链**：上一镜尾帧截图作为下一镜首帧参考 → 转场自然+时序连续（**我们完全没用**——LMD/Seedance API 均支持 first/last frame 双图，i2v_template 未实现）。
3. **多景别首帧**：多角度工具+垫图（依赖 Seedream 参考能力）→ 特写/中景/全景交替（**我们已识别的瓶颈**；CogView 无垫图，替代路线见 §四）。
4. **BGM 合成+自动渲染**：成片链尾自动混 BGM（我们 A1 级已规划，ffmpeg 实现）。

## 三、我们现状 vs 对方（差距重排）

| 能力 | 对方 | 我们 | 差距性质 |
|---|---|---|---|
| 剧本/分镜生成 | Agent 全自动 | GLM 脚本化（A5 已验） | 工程（可补） |
| 全局资产引用 | 自动拆解+@引用 | 官定底图单图 | 工程（**i2v 多参考**：Seedance 支持图≤9 参考，NoToken mini 同协议——**未测**） |
| 首尾帧转场 | 有 | **无** | 工程（API 支持，未用） |
| 多景别首帧 | 多角度+垫图（Seedream） | 无 | **模型+工程**（CogView 无垫图；i2v 多参考/官定图裁切为替代） |
| BGM/包装 | 内置 | ffmpeg 方案已验证可行 | 工程 |
| 视频档位 | Seedance 全档+4 家 | mini 单档（NoToken 分组限制） | **供应商限制**（问聚合档/换渠道） |
| 图片档位 | Seedream/MJ 系（垫图） | CogView-4（无垫图） | **模型能力差距** |
| 一键流 | 全自动 | 半自动（缺 5 零件） | 工程 |
| 合规 | 报白+拦截+积分返还 | governance 文档化 | 已同级（方式不同） |

## 四、复刻方案 v3（替换 v2 的 A/B/C）

### 第一优先：两大未用 API 能力（¥4-8 试验，杠杆最大）

1. **首尾帧转场链**：compose 前每镜抽尾帧 → 作为下一镜 i2v 的 last_frame/first_frame 参考输入。Seedance 火山协议支持（LMD videoClient 已有 first/last_frame 字段实现）。**预期效果：转场丝滑+镜头连贯**——对方"大片感"的核心。试验：2 镜头链（~¥8：2×4s）。
2. **i2v 多参考**：官定图+场景图双参考（role: reference_image）→ 不同景别/场景中保持 Dr.咪一致。**这直接解多景别瓶颈**（不必依赖 Seedream 垫图）。试验：1 条（~¥4）。此前 M3 失败系 role 参数问题（经验在 notoken-relay-audit）。

### 第二优先：A1 纯后期（¥0，沿用 v2 并细化）

3. BGM+猫叫 ducking 混音、花字字幕、xfade 叠化、片头尾模板、空镜 Ken Burns（滤镜 9/9 已验证）——合成器重写（首尾帧链+混音+多轨字幕一体设计，B5 素材回归三验收）。

### 第三优先：成本与档位（待拍板沿用 v2）

4. 镜头节奏/预算三选一（¥59-85 重算不变）；Seedance 正式档 1 镜对比；NoToken 聚合档询问（此前悬置项，0.2 点/秒若开通则成本降 80%）。

### 第四优先：一键流（等 1-3 有对比结果）

5. make_episode.py（补 5 零件：CogView 出图/分镜生成/混音器/P10 闸门/虹膜色相闸门）。

### 明确不做（Ponytail）

视频转绘、无限画布、调度台 3D、剧本协同/翻译、官方资产市场——不在医学科普猫医生关键路径。

## 五、验证方式

咖啡第一集重做：镜头 1-2 用首尾帧链+多参考（S2 试点）→ 全片 A1 包装 → 与 B5 成片新旧同框对比；用户目视验收（对方成片仍无样片，目标="对齐手册描述的成片规格"）。
