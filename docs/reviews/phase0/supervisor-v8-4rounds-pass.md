## 四轮要点

1. **选板测绘（有条件通过）**：8 张 v8 底板仅 v8_real_4 可用（唯一空白卡正对镜头）；管子与卡片无重叠（距离 ≥40px），**"被听诊器挡字"在本底板物理上不存在，监工拒绝编造坐标**，按完整贴字推进；delogo 修补痕迹可见 → 改 OpenCV TELEA inpaint；写实度"光靠提示词不够，必须后期"→ 确立做旧管线。卡片测绘：TL(634,709) TR(711,691) BR(714,737) BL(637,755)，可印字区 x640-708/y698-749，倾角 ≈13°。
2. **黑楔打回**：全尺寸字层 rotate 空角默认填黑，multiply 后四角变黑（zoom 局部图漏检，教训：呈报必须附全图+程序边缘检查）。修复：fillcolor=(255,255,255)。
3. **通道互换打回**：PIL(RGB) 数组直接喂 cv2(BGR) 编码/写盘 → 猫眼琥珀变蓝、字深蓝变棕；亮度型自检抓不到颜色问题。修复：后期全程 RGB 域、cv2 交界处显式 [::-1]。
4. **放行条件落实后 PASS**：inpaint_compare 左侧补 RGB；颜色门禁换通道相关系数指标（corr(R,R)=0.99 vs corr(R,B)=0.84，互换即拦截）+ 采样 5x5 + 边缘差 >3pp 拦截 + 字区 ≤20 拦截，全部 sys.exit(1) 硬门禁；做旧预设 light/medium 两档供用户选。
